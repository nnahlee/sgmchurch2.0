1. SSG — Static Site Generation
Benefits
- Very fast responses because HTML is already generated.
- Lower server workload and often lower hosting costs.
- Excellent for public pages and SEO.
Tradeoffs
- Content can become outdated until revalidation or a rebuild.
large content can increase build time

2. SSR — Server-Side Rendering

Best for request-specific content
Benefits
- Can use current data at request time.
- Can personalize HTML using cookies, headers, and session information.
- Changes in the data source can appear on the next request without rebuilding the page.

Tradeoffs
- The server must do work for each request, unless caching
- A slow database or API can delay the response i.e slower.
- More runtime resource usage and potential hosting cost.
